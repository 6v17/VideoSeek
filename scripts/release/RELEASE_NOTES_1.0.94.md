## VideoSeek 1.0.94

### 安装包怎么选
· **VideoSeek-1.0.94-Full-Setup.exe** — 含 FG-CLIP2 / FFmpeg / 中文字幕 OCR，装完即用，推荐新用户装
· **VideoSeek-1.0.94-Setup.exe** — 不含运行资源，沿用已有模型，推荐老用户升级

两个安装包使用和 1.0.93 相同的安装 Id，覆盖安装会进原来的目录。完整包首次启动会导入自带 runtime；已经配好模型的机器只补缺的文件，不改当前正在用的检索模型。

### 模型与检索
· 新增本地 FG-CLIP2，完整包默认带这套
· 图片文件夹可同步进同一工作区，在搜索页「找图」
· 可选 DashScope 云端 VL 嵌入（主动开启才会上传抽帧和查询）
· 相近镜头会收成一组，展示得分那一帧
· 精确搜索一页展示；深翻页继续取到索引不够为止，到 10,000 条会提示已到上限
· 竖屏视频入库前裁掉上下静止边
· 结果表格和网格改为按可视区域回收，长列表更稳

### 预览
· 搜索预览改为页内铺满，不再弹独立窗口
· 空格从当前位置继续播，R / 重播按钮才重放命中片段
· 播放、重播、清除、全屏改为紧凑图标，夜间主题也能看清

### Agent 与 MCP
· 本机 Agent API 可通过 stdio MCP 接入
· 打包后的 VideoSeek.exe 可直接给 MCP 用
· 搜索可返回缩略图；成片草稿支持配乐、较长镜头和跨查询去重

### 其它
· 去掉视频下载页，安装包不再带站点下载器
· 设置里可复制错误报告、导出日志（用户路径会打码）
· 超过一小时的时间码按小时显示
· 窗口缩小时界面跟着收，不再裁掉卡片
